на практике. Один-два предложения, без разгона.

## Раздел

### Подраздел

Текст. Код — в блоках с указанием языка:

```java
// пример
```

Схемы и сводки — в блоках `text`:

```text
A → B
```

---

## Типичные ошибки

### Короткая формулировка ошибки

Одно-два предложения: в чём она состоит и чем оборачивается.

### Ещё одна

Формулировки начинаются с глагола или существительного, без нумерации.

## Краткая памятка

Сжатые схемы для повторения за пять минут до собеседования — только блоки `text`,
без пояснений.

```text
ключевая схема
```

---

## Краткий ответ для собеседования

Связный текст на две-четыре минуты устного ответа. Проза без списков и без
markdown-разметки внутри — так, как это будет произнесено вслух.

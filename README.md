# Java Backend Interview Preparation

Репозиторий для системной подготовки к техническим интервью на позиции Java Backend Developer.

## Направления подготовки

- Java Core
- Collections Framework
- JVM
- Java Concurrency
- Spring Framework
- Spring Boot
- HTTP and REST
- PostgreSQL and SQL
- JPA and Hibernate
- Apache Kafka
- Testing
- Backend Architecture
- System Design
- Docker and CI/CD
- Git

## Формат подготовки

Для каждой темы:

1. Изучение теории.
2. Разбор внутренних механизмов.
3. Написание небольших примеров на Java.
4. Ответы на вопросы технических интервью.
5. Контрольное повторение после завершения темы.

# Java Backend Interview Preparation

Репозиторий для системной подготовки к техническим интервью на позиции Java Backend Developer.

## Направления подготовки

- Java Core
- Collections Framework
- JVM
- Multithreading
- Spring Framework
- PostgreSQL
- Hibernate
- Kafka
- Testing
- System Design

## Стек

- Java 21
- Gradle

## Структура

- `docs` — конспекты и ответы на вопросы;
- `src/main/java` — небольшие демонстрационные примеры;
- `src/test/java` — тесты для учебных примеров.
